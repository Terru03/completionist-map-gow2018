# v0.9.6.1 installer hotfix

Current test package: `Completionist-Map-v0.9.6.1-INSTALLER-FIX.zip`

## Regression in v0.9.6

The installer correctly prepared the v0.9.6 changes, including:

- `MaxIn 6 -> 2.5`
- `CursorScale_Min 0.50 -> 0.05`
- `CursorSnap_Enabled 1 -> 0`
- pinned Raven/Nornir reference sources

It then aborted before writing the runtime override with:

```text
Hidden-player map-centre patch is missing.
```

This was an installer validation-order bug. `PLAYER_HIDDEN_CENTER` was validated before `$hiddenPlayerFocusRegex.Replace(...)` had added that code to `mapmenu.lua`.

## v0.9.6.1 fix

No gameplay, marker, filter, compass or lifecycle logic changes from v0.9.6.

The premature validation is removed. The existing post-replacement validation remains immediately after the hidden-player-focus regex patch is applied.

Retained v0.9.6 behaviour:

- v0.9.4 proven `UI.SetIsClickable()` + collision-selection path
- `CursorSnap_Enabled = 0`
- `CursorSnap_Strength = 0.0`
- custom marker scale `1.0`
- stale stock compass destination cleared before custom Raven/Nornir tracking
- hidden Kratos remains the opening-map focus
- custom filters
- Raven/Nornir lifecycle
- deep zoom `MaxIn = 2.5`
- no manual-hover experiment

## Safety

- no `Map.ChangeMarkerState()`
- no synthetic `game.Compass.ShowMarker()`
- no puzzle/quest progression mutation
- no synthetic save writes
