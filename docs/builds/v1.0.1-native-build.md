# v1.0.1 Native Build And Nexus Review

Release date: 2026-10-04. Source branch: `codex/startup-compatibility`.

## Requirements

- Windows x64.
- Visual Studio 2022 with Desktop development with C++, MSVC v143, Windows SDK, and MASM. Release build used MSVC 19.44.
- CMake 3.24 or newer, Git, Python 3, and Windows PowerShell 5.1. Release build used CMake 4.0.1 and Python 3.14.
- Use short checkout path. Native fixture reads need full file paths below Windows `MAX_PATH` limit.
- Close God of War before tests. Game uses bridge port; installer tests reject open game.

## Build Both DLLs

Run in PowerShell. Stop if any native command returns nonzero exit code.

```powershell
git clone --branch codex/startup-compatibility https://github.com/Terru03/completionist-map-gow2018.git
Set-Location completionist-map-gow2018
$python = (py -3 -c "import sys; print(sys.executable)").Trim()

git clone --branch v1.3.1 --depth 1 https://github.com/madler/zlib.git build/deps/zlib
$zlibCommit = (git -C build/deps/zlib rev-parse HEAD).Trim()
if ($zlibCommit -ne '51b7f2abdade71cd9bb0e7a373ef2610ec6f9daf') { throw 'Wrong zlib commit' }
$zlib = (Resolve-Path build/deps/zlib).Path.Replace('\', '/')
$capture = (Resolve-Path archive/field-logs/runtime-captures/staged-wad-bitstream-raven-20260921-060345-c2c9bcc1).Path.Replace('\', '/')

cmake -S native/raven-authority-bridge -B build/review-bridge -G "Visual Studio 17 2022" -A x64 "-DPython3_EXECUTABLE=$python" "-DFETCHCONTENT_SOURCE_DIR_ZLIB=$zlib" "-DCAPTURE_ROOT=$capture"
cmake --build build/review-bridge --config Release

$bridge = (Resolve-Path build/review-bridge/Release/dxgi.dll).Path
$bridgeHash = (Get-FileHash -LiteralPath $bridge -Algorithm SHA256).Hash.ToLowerInvariant()
cmake -S native/collectible-marker-capacity -B build/review-capacity -G "Visual Studio 17 2022" -A x64 "-DPython3_EXECUTABLE=$python" "-DCOLLECTIBLE_UPSTREAM_SHA256=$bridgeHash"
cmake --build build/review-capacity --config Release

ctest --test-dir build/review-bridge -C Release --output-on-failure
ctest --test-dir build/review-capacity -C Release --output-on-failure
py -3 -B tools/test_nexus_package.py -v
```

Release uses zlib v1.3.1 at commit above. Explicit `FETCHCONTENT_SOURCE_DIR_ZLIB` override matches release dependency and avoids separate FetchContent checkout. CMake's `925af44f3cde53c6b076611c297850091b5dc7bb` names annotated tag object for same commit.

Resolved `CAPTURE_ROOT` removes `native/raven-authority-bridge/../..` from fixture paths. Deep paths can cause `missing fixture` test failures even when files present. This affects test file reads, not shipped mod startup.

Outputs:

- `build/review-capacity/Release/dxgi.dll`: game-root DXGI proxy and engine capacity patches.
- `build/review-bridge/Release/dxgi.dll`: read-only completion-state bridge. Package installs it as `mods/completionist-map/native/collectible-base-dxgi.dll`.

Outer DLL pins exact SHA256 of companion. Always compute hash after building bridge, then configure capacity DLL with that hash. Do not mix DLLs from separate builds. Build paths, toolchain, and linker metadata can change binary hash; no byte-identical rebuild claim.

## Package

Startup update keeps v1.0.0 Lua, map, and art payloads unchanged. Supply extracted v1.0.0 package as `--source`; source must sit outside `dist/nexus/CompletionistMap-v1.0.1`.

```powershell
$payloadSource = Read-Host 'Path to extracted v1.0.0 package'
py -3 -B tools/build-nexus-package.py --source "$payloadSource" --capacity-dll build/review-capacity/Release/dxgi.dll --bridge-dll build/review-bridge/Release/dxgi.dll
```

Packager makes `dist/nexus/CompletionistMap-v1.0.1.zip`. It checks companion pin, updates native manifest, and includes installer, uninstaller, README, and payload hashes. No game EXE or loader DLL packaged. Generated ZIP timestamps can differ; ZIP hash below identifies actual uploaded file, not every rebuild.
