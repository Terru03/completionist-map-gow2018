## Verify or roll back

Run from this checkout in Windows Python. Verification is read-only:

```powershell
py -3.14 -B tools/v0.10.5/install-collectible-completion.py verify --operation build/collectible-completion/backups/7d93a92c6f474c4aa72bacd95d9ff94b/operation.json
```

With GoW closed, restore the working map/filter recovery package:

```powershell
py -3.14 -B tools/v0.10.5/install-collectible-completion.py rollback --operation build/collectible-completion/backups/7d93a92c6f474c4aa72bacd95d9ff94b/operation.json
```

Rollback uses this operation's own backups and refuses unrelated edits. The
older recovery rollback would restore the package that had map-open crashes;
use the completion operation above for this change.

For a new build, first restore the working baseline, then freeze into a fresh
output directory with `build-collectible-completion.py --freeze --output <dir>`.
Build with the same `--output`. Existing frozen inputs deliberately reject source
drift. Install with `install-collectible-completion.py install --output <dir>`
while GoW is closed. Do not modify immutable package files or their reports.
