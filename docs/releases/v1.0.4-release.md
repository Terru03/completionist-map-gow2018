## Reproducing the package promotion

Run from the repository root, supplying the exact tested ZIP and a new output
path. This operation uses only the Python standard library and does not rebuild
the DLLs, game resources or Lua payloads.

```sh
python tools/promote-tested-chest-release.py \
  --source /path/to/CompletionistMap-v1.0.4-chest-tracking-test.zip \
  --output dist/nexus/approved-chest/CompletionistMap-v1.0.4.zip
```

Native build entry points are `native/raven-authority-bridge/CMakeLists.txt` and
`native/collectible-marker-capacity/CMakeLists.txt`. The latter must be configured
with the rebuilt bridge's SHA-256 as `UPSTREAM_DXGI_SHA256` so it accepts that
companion. Build and test details are in the startup analysis above. A source
rebuild can produce different DLL hashes from the preserved tested release;
the release provenance identifies the exact bytes submitted to Nexus.
