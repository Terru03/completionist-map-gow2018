# Completionist Map v1.0.5

Released 2026-10-13. **v1.0.5** introduces universal PC build compatibility across all God of War (2018) PC versions, while preserving all proven v1.0.4 chest tracking and Raven authority features without regressions.

The exact release package, checksum, and payload provenance are in
[`releases/v1.0.5/`](../../releases/v1.0.5/).

## Changes and Improvements

- **Universal Game Build Compatibility:**
  - Removed hardcoded executable version and hash restrictions from the native bridge runtime (`dxgi.dll`).
  - Updated installer (`Install.bat` / `install.ps1`) to perform dynamic, non-blocking executable detection instead of rejecting non-official builds.
  - Fully supports Steam, Epic Games, GOG, and non-official builds (CODEX, repacks, etc.) across various game patch versions.
- **Chest Tracking & Provenance (Zero Regressions):**
  - Retains the exact player-verified v1.0.4 chest tracking fix in `mapmenu.lua` (SHA256: `89312da4a21d22bd651fe30ead5d45abddee6b318781fa9bd965315ada349787`), verifying inner owner ancestry so opened wooden and red/coffin chests disappear properly.
  - Preserves Odin's Raven native authority tracking, 3D compass waypoint clearing, and collectible state persistence.
- **Native Stability:**
  - Retains Windows 10/11 compatibility layer protections to avoid early ntdll crashes.

## Native map filters

All custom markers are organized into dedicated collectible-category filters integrated with the game's native map filters. Use the normal map filter controls to focus on the marker types you want to see, such as Ravens, chests or Artefacts. Related Nornir puzzle markers are grouped under the Nornir Puzzle filter.

The packaged README has been refreshed to document the existing native map category filters. Only `README.txt` changed; all 26 other archive entries, including every runtime payload and installer file, remain byte-for-byte identical to the prior v1.0.5 archive.
